# Changelog

All notable released changes will be documented here. The project intends to follow Keep a Changelog principles and Semantic Versioning once a stable release process is adopted.

## [Unreleased]

### Added

- Initial Node.js API, dashboard, agent orchestrator, five domain-agent prototypes, A2SPA signing demonstrations, and Copilot Studio export.
- Replaced the discontinued native client with an installable responsive PWA and removed its dependency tree.
- Added a global public-sector charter, A2SPA-R design profile, and private-source governance controls.
- Repository security configuration, environment-driven credentials, contribution workflow, and project documentation suite.
- Externally verified A2SPA-R authorization, local replay protection, signed receipts, OIDC/JWKS identity, and tamper-evident audit exports.
- Signed versioned policy packs with approval, binding, purpose, prohibition, human-review, rights/remedy, revocation, rollback, and decision audit.
- Development queue/idempotency and protected operational metrics references, plus persistence/observability runbooks.
- Accessible localized PWA development controls, policy self-approval denial, release evidence automation, and corresponding assurance records.

### Security

- Removed hardcoded API keys and local network addresses before initial publication.

### Known limitations

- No production persistence/telemetry provider, managed KMS/HSM integration, independently validated jurisdictional pack, approved SLO/RTO/RPO, production deployment, or independent assessment.

Release entries must describe user-visible impact and link to tags/releases. Internal task progress belongs in `PROJECT_STATUS.md`.
