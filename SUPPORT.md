# Support

## Scope

The project is pre-production and has no guaranteed support SLA. Use GitHub issues for reproducible, non-sensitive defects and feature proposals. Use the private security channel described in `SECURITY.md` for vulnerabilities. Do not submit credentials, private keys, personal data, confidential government information, or unredacted logs.

## Useful report contents

Provide the commit/tag, component, operating system, Node/npm or Expo versions, expected and actual behavior, minimal synthetic reproduction, sanitized logs, and troubleshooting already attempted. Maintainers may close reports that cannot be reproduced or fall outside project scope.

## Boundaries

Public support does not provide legal advice, compliance certification, incident-response retainers, production guarantees, or recovery of lost credentials/data. Production support terms, escalation contacts, coverage hours, severity definitions, and response targets must be approved before launch.
