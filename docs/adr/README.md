# Architecture Decision Records

Copy the template below into the next zero-padded file, open it with status `Proposed`, and submit it with or before implementation.

```md
# ADR-NNNN: Decision title

Date: YYYY-MM-DD
Status: Proposed
Decision owners: roles or teams

## Context
## Decision
## Alternatives considered
## Consequences
## Security, privacy, and operations
## Validation and review date
```

Statuses are Proposed, Accepted, Rejected, Deprecated, or Superseded. Link superseding records in both directions.
